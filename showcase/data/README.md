`../scripts/capture-cases.py` 仅为显式执行的本机准备脚本，不被页面或构建入口引用。它会创建演示数据并调用真实模型，因此普通启动/构建/测试不运行它。已有完整公开记录时脚本拒绝覆盖；更新素材需重新明确范围与用量授权，不能由访客触发，也不应放进 CI。
