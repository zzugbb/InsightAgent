## 证据包导出

```bash
export INSIGHT_AGENT_ACCESS_TOKEN="<access token>"
backend/.venv/bin/python scripts/export_acceptance_evidence.py \
  --api-base-url http://127.0.0.1:8000 \
  --session-id <会话 UUID> \
  --output-dir /tmp/insightagent-acceptance-evidence-<date>
```

可选 `--task-id` 多次指定，仅导出相关任务导出件。输出不含密钥、不含消息正文（仅指纹与低敏元数据）。
