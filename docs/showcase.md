# 公开展示与发布

[在线展示](https://zzugbb.github.io/InsightAgent/) · [案例回放](https://zzugbb.github.io/InsightAgent/demo/) · [运行命令](../showcase/README.md) · [验证基线](acceptance.md#公开项目展示)

展示站用于浏览项目能力、架构和执行证据，位于同仓库独立的 `showcase/`。它已发布至 GitHub Pages，构建产物为静态 HTML、JS、CSS 和公开素材，不依赖完整工作台、FastAPI、PostgreSQL、Chroma 或模型服务。完整应用仍需独立运行与验收。

## 页面与交互

| 页面 | 内容与操作 |
| --- | --- |
| 首页 `/` | 项目介绍、工作台截图、01 核心能力、02 系统架构、03 任务执行、04 工程实践、验证边界及源码入口 |
| 案例 `/demo/` | 两个案例、原任务与恢复分支、回答、时间线/流程图、节点详情、来源与已记录用量 |

系统分层保留 Next.js → FastAPI → 模型 API / PostgreSQL / Chroma 总览；任务执行图展示规划、工具、反馈、回答和保存。两图直接展示，节点可点选查看职责与源码依据，支持八步讲解、暂停、重播、复位及全图查看。沿用工作台的深色与绿色视觉，适配桌面、手机和键盘操作。

任务执行图进入视野并加载完成后播放一次（约 1.8 秒/步）；案例进入或主动切换记录后播放一次（约 1.1 秒/步）。结束停留；执行图离屏或后台暂停，案例切至后台暂停，返回不自动恢复。案例查看节点即暂停，复位保持停止。减少动态效果时仅手动播放，不循环或自动切换案例。

架构动画是概念示意；案例回放来自保存的执行记录，阅读节奏不等于原始耗时或实时 SSE。流程图仅显示明确记录的依赖与决策关系，不从记录顺序推造 DAG，也不展示模型内部思维。

## 案例与素材

| 案例 | 来源与边界 |
| --- | --- |
| 知识检索与计算 | 真实 glm-5.3 + 专用合成资料；实际检索、计算并回答 14 万元，保留来源和版本 |
| 失败与独立分支恢复 | 原任务为受控 fixture：实际计算后决策注入 429；独立分支真实模型计算 `(2+3)*2` 得到 10。恢复成功不覆盖原失败，也不代表供应商发生过该故障 |

来源、执行基线、耗时、用量和白名单处理见[素材说明](../showcase/data/README.md)。工作台截图通过隔离 HTTP fixture 加载公开案例，不是截图时重新执行真实模型或完整后端验收。未知用量保持未知，配置费用估算不等于供应商账单。

公开数据只来自 `showcase/data/` 与 `showcase/public/`，不读取根目录 `data/`、env、数据库或私人会话。页面不接受 Key、自由提问、文件上传或登录，不保存访客任务，不调用完整应用 API 或模型，不包含统计追踪。

现有公开记录无需重新采集。更新素材时先明确数据处理范围与真实模型用量授权；采集脚本只显式本机运行，不接入页面、构建或 CI。凭据通过受控运行时读取，不进入参数、日志、截图、静态 JSON 或托管环境。素材按字段白名单、公开别名与来源核对后提交。原有数据容器的保护仍遵循[恢复规则](pilot-deployment-preflight.md#开发栈备份恢复)。

## 发布与维护

[showcase-pages 工作流](../.github/workflows/showcase-pages.yml)使用 Node 24，执行安装、类型、lint、格式、Node tests 和静态构建，只上传 `showcase/out/`。

- main 上 `showcase/**` 或工作流自身改动自动检查并发布；PR 只检查，main 手动运行用于重试。
- Pages 使用 GitHub Actions 来源和默认项目地址；构建设置 `NEXT_PUBLIC_BASE_PATH=/InsightAgent`，链接与图片使用相同前缀。本地根路径构建不设置前缀。
- 修复或回滚通过 main 上的修正 / revert 提交重新发布，核对对应运行结果；旧 CI 不代表新提交通过。
- 路径或交互变更复验首页、案例直接访问与刷新、图片、懒加载、回放、移动端和减少动态效果。纯文档变更检查链接、命令和 hygiene。

运行、静态预览和浏览器复验命令集中于[展示 README](../showcase/README.md)，实际发布与线上证据集中于[验收基线](acceptance.md#公开项目展示)。构建、依赖、缓存和临时报告不提交。

展示范围固定为现有两页与两个案例，不预设后续版本、视频或新增 Agent 功能。当前发布未使用 Vercel、Sites、自定义域名或付费资源；完整应用的 HTTPS、访问边界、双存储持久化、备份恢复与业务签收另按[试点部署指南](pilot-deployment-preflight.md)验收。
