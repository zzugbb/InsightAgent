# 公开项目展示：固定交付范围

范围确认日期：2026-10-09；2026-10-10 按维护者明确需求补充既有页面的架构交互与阅读引导，仍为同一版固定交付。本文是一次性展示交付的范围与验收说明，不是实时开发计划。独立应用与公开素材已实现并完成本地验证，推送与公开发布尚未执行；结果统一记录在[验收基线](acceptance.md#公开项目展示)。

## 目标与边界

让招聘方和开源访客在 1–3 分钟内理解 InsightAgent 的定位、查看执行证据，并进入 GitHub 核查源码。线上提供预设案例的交互回放，完整应用保留本地运行能力。

交付为 GitHub 开源仓库、独立展示应用及 GitHub Pages 默认项目地址。不购买服务器、域名或套餐，不使用 Sites，不处理简历。本次固定范围完成后封板，只按可复现问题维护；不预设第二版、视频补充或新增功能路线。

展示站发布不表示完整应用已部署，不改变业务资料、目标用户签收、安全与部署恢复仍待外部验收的状态。原始计划 `data/insightagent.plan.back.md` 始终只读。

## 目录与运行

展示应用位于同一仓库的 `showcase/`，独立依赖、构建和运行。GitHub Pages 工作流只构建该目录并发布静态导出产物；main 上展示目录或发布工作流改动自动构建并发布，PR 只检查；保留 main 手动运行入口。项目子路径通过构建时的公开前缀适配，本地根路径预览保留。

```text
showcase/
├── app/                 首页与案例体验页
├── components/          展示、回放和 Trace 组件
├── data/                专用合成资料与已复核的公开案例记录
├── public/              公开截图等静态素材
├── package.json         独立依赖与构建命令
└── README.md            展示应用运行与发布说明
```

以上目录已创建，运行与发布设置见[展示应用 README](../showcase/README.md)。采用 Node 24.x、npm 和独立 Next.js/React 应用，构建目标为静态站点。优先复用可独立使用的 Trace 数据契约、布局或展示逻辑，不引入鉴权、后端 API 或完整工作台编排，不改现有后端运行契约。

公开页面不依赖 FastAPI、PostgreSQL、Chroma 或模型服务，不配置 Key，不设置指向本机或生产后端的 API 地址。`showcase/data/` 只保存专用公开案例，不读取根目录 `data/`、环境文件或数据库。

## 页面与视觉

| 页面 | 固定内容 | 主要动作 |
| --- | --- | --- |
| 首页 `/` | 项目定位、真实工作台截图、核心能力、交互架构图、工程亮点、验证边界、GitHub 入口 | 进入案例、查看两张架构图/讲解/节点职责、查看源码 |
| 案例体验页 `/demo/` | 两个预设案例、问题与回答、执行时间线、流程图、节点详情、来源说明 | 选择案例、查看观察重点、回放和查看证据/全图 |

首页顺序为项目介绍与主截图 → 01 核心能力 → 02 系统架构 → 03 任务执行 → 04 工程实践 → 验证边界与源码入口。原架构区拆成两段、工程内容顺延，不新增第五段或交付阶段。工程亮点聚焦 SSE 与增量同步、工具执行与 Trace、RAG 后台导入与治理，不堆叠全部接口和测试日志。

沿用现有工作台的色彩、字体与组件语言，真实界面截图作为主要视觉素材，排版清楚并保留留白。案例页以执行记录为主、节点详情为辅助区域。第一屏展示 InsightAgent 和案例入口，不新增联系表单、定价、用户评价或宣传数字。

架构区沿用整体深色、绿色强调色、字体和留白。原有 Next.js → FastAPI → 模型 API / PostgreSQL / Chroma 总览完整保留为“系统分层”；两图分别直接展示，不需要视图切换。“任务执行”展示输入、规划、执行、反馈循环、回答与结果保存，工具分支仅以现有检索和计算为例。支持点选职责、源码依据、八步讲解/暂停/重播/复位与全图查看，手机优先聚焦当前节点。该动画是架构示意，不伪装成真实执行或 SSE，不增加通用浏览器、Shell、MCP/A2A 等未实现能力。

中文为主，支持桌面和手机，必要技术名称保留英文。进度、节点选择与详情展开采用克制过渡，尊重减少动态效果的系统设置；任务执行图进入视野且完成加载后自动讲解一次，结束后停留；离开视野或页面切至后台即暂停，返回不自动恢复，手动操作后不再触发自动播放。减少动态效果时只提供手动播放；案例进入页面或主动切换记录后播放一次，结束停留，不自动切换案例或分支；减少动态效果时仍由访客显式触发。按钮支持键盘，焦点与选中状态清晰。

## 两个固定案例

| 案例 | 展示内容 | 证据要求 |
| --- | --- | --- |
| 知识检索与计算 | 合成资料中的事实、来源与版本、计算工具输入输出、最终回答及已记录用量 | 核对真实检索与计算 action、回答和 Trace，不只看数值或 completed |
| 失败与分支恢复 | 原任务问题、编辑明确输入后的独立分支和恢复结果 | 分开保留结论，恢复成功不覆盖原失败，不宣称任意步骤恢复或写入回滚 |

不为制造随机失败反复请求真实模型。若实际失败无法稳定复现，使用已有隔离 fixture 准备受控失败部分，明确标注替身来源；真实模型恢复部分单独记录。不得编造模型错误、实际工具结果或调用记录，不增加生产故障开关。

固定交互为：选择案例；查看恢复案例的原任务与分支；播放、暂停、重新播放；时间线与流程图切换；选择节点查看公开输入输出、状态、引用与已记录用量。各案例在输入下提示观察重点，流程图区提供明确“查看全图”按钮。结束后保留记录供自由查看；进入案例页自动播放默认记录；主动切换案例或原任务/恢复分支后复位进度与选择并播放对应记录一次，重复点击当前案例/分支不重播。查看节点、切至后台或启用减少动态效果时暂停，返回不自动恢复；复位后保持停止，播放结束不循环或自动切换记录。减少动态效果时只手动播放。

这是保存执行记录的网页交互，不是 GIF 或视频。播放节奏可为阅读而缩短，需注明调整，不能伪装成原始耗时、实时 SSE 或新的任务执行。流程图仅使用明确记录的依赖，记录顺序与依赖关系分开，不从 seq 推造 DAG。Trace 展示执行依据，不展示模型内部思维过程。

不增加在线下载入口；完整应用的导出能力可通过截图或文案介绍。未知用量保持未知，费用如展示需标注配置估算，不是供应商账单。

## 案例准备与素材保护

维护者明确授权：准备上述案例时，可使用此前保存的真实模型 Key 调用真实模型并产生少量用量，无需重新索要 Key。公开页面只回放记录，不调用模型。此授权不包含上传 Key、私人会话、数据库或完整配置。

使用新建专用合成资料与演示会话，通过已有任务/验收接口获取证据。凭据通过受控运行时读取，不打印、不写入命令参数或产物，不进入静态 JSON、截图、代码或托管环境。素材由开发者自动准备和采集，维护者无需录屏或写文案。

先检查已有服务，再安排启动；Docker、本机端口、浏览器和依赖安装按[运行手册](development-runbook.md)的权限流程执行。旧 Chroma 实际数据位于容器 `/data`，不得重建、删除或用新 Compose 配方覆盖；保留现有容器与卷，不假设已有可恢复备份。

不导出现有私人会话、不迁移数据库、不替换用户模型设置。确需扩大数据处理范围时另行取得授权。截图只拍合成演示内容，不包含登录凭据、Key、私人会话列表、非必要用户标识或敏感网络配置。

公开记录采用必要字段白名单，保留步骤、结果、来源和已记录用量。每个案例记录来源类型、准备日期、源码基线、验证结论及限制。采集日志为临时产物，不提交；经复核的案例 JSON 和截图作为公开展示素材提交。未经来源与敏感信息复核，不视为可发布素材。

## 明确排除

- 视频制作、GIF 主体验、实时模型调用、访客 Key、自由提问或编辑任务。
- 登录注册、上传资料、在线知识库、用户数据保存、完整应用公网 API。
- 搬运全部任务中心、设置或治理页面，新增 Agent 能力、重写后端。
- 新数据库、向量服务、云服务器、Sites、付费套餐、自定义域名、多语言。
- 简历、营销表单、统计追踪、周期自动更新及预设后续版本。
- 写入工具并行、HTTP/DAG checkpoint、ESLint 10 或重新开启原工程收尾。
